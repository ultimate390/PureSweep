## 💡 Что это

**PureSweep** — бесплатная утилита для чистки и настройки Windows. Умеет примерно то же, что платные комбайны: находит мусор, чинит реестр, разгоняет автозагрузку, ищет дубликаты и затирает данные без следа.

Отличие одно, но важное: **если функцию нельзя сделать честно — её здесь нет.** Никаких красивых кнопок, которые ничего не делают. Программа скажет прямо, что не может, и подскажет, чем это сделать.

## 🚀 Установка

### Вариант 1 — скачать готовое
Зайди в [**Releases**](../../releases) и забери `PureSweep.exe`. Установка не нужна, это один файл.

> ⚠️ **Антивирус может ругаться.** Это ложное срабатывание: так реагируют на **любые** программы, собранные PyInstaller — он упаковывает Python внутрь exe. Код открыт, можешь проверить сам или собрать из исходников.

### Вариант 2 — собрать самому
```bash
git clone https://github.com/ultimate390/PureSweep.git
cd PureSweep
pip install pyinstaller pillow psutil
python -m PyInstaller --onefile --noconsole --icon assets/PureSweep.ico --add-data "assets;assets" main.py
```
Готовый файл будет в папке `dist`.

### Просто запустить без сборки
```bash
python main.py
```

## 🤝 Чего здесь нет (и почему)

Мне важнее, чтобы ты доверял программе, чем чтобы список функций был длиннее.

| Функция | Почему её нет |
|---|---|
| 🗜️ Сжатие реестра | Требует перезаписи ветвей при выключенной системе. Из работающей Windows — риск не загрузиться |
| 🔐 Шифрование папок | Самодельная криптография = ложное чувство защиты. Бери **BitLocker** или архив **7-Zip с AES-256** |
| ↩️ Восстановление файлов | Нужен посекторный движок сканирования диска. Честнее сказать: **PhotoRec** или **Recuva** |
| 👁️ Показ паролей браузера | Расшифровывать чужие хранилища — плохая идея. Программа покажет список, управляй ими в браузере |
| 🔧 Обновление драйверов | Без своей базы драйверов это лотерея с кирпичом вместо ПК |

## ⚠️ Здравый смысл

- 🔑 Запускай **от администратора** — иначе системные папки и реестр останутся нетронутыми
- 💾 Реестр чистится только после успешного бэкапа, но **точка восстановления лишней не будет**
- 🔥 Шредер и затирание свободного места — **необратимы**. В этом весь смысл
- 🌐 Закрой браузер перед чисткой cookies, иначе файлы заблокированы

## 🛠️ Под капотом

`Python 3` · `tkinter` · `psutil` · `PyInstaller`

Без тяжёлых зависимостей и без интернета: программа ничего никуда не отправляет. Весь код — в одном читаемом файле.

Пара технических мелочей, которыми я доволен:
- 🔤 Умный декодер текста — подбирает кодировку и **чинит кракозябры** вроде `РџРµСЂРµРґ` → `Перед`
- ✅ Каждая системная команда проверяется по коду возврата: никаких «Готово» там, где ничего не вышло
- 🪟 Windows 11 определяется по номеру сборки — стандартные методы Python упрямо зовут её «десяткой»
